# FuityFly Whitepaper Site

Static site built with plain HTML, CSS and JS. Vite is used only for the dev server and the build.

```
npm install
npm run dev      # local server with live reload
npm run build    # output to dist/
```

## Layout

```
index.html, banana.html, brain.html, sdk.html, sim.html   pages
_template.html     copy this to start a new page
css/style.css      all styles, grouped into numbered sections
js/main.js         nav, footer, table of contents, prev/next links, math
assets/            images and icons
```

The nav, footer, table of contents and prev/next links are generated by `js/main.js`, so each page only contains its own content.

## Add a page

1. Copy `_template.html` to `newpage.html` and fill it in.
2. Add `{ file: "newpage.html", label: "Nav label", title: "Full title" }` to `PAGES` in `js/main.js`.
3. Add `"newpage"` to the `pages` list in `vite.config.js`.

## Building blocks

These are all shown in `_template.html`:

| Class | Use |
|---|---|
| `section id=…` + `h2` | A section. It is added to the table of contents automatically. |
| `figure` > `.fig-body` + `figcaption` | Diagram or image |
| `.eq` | Display math (KaTeX, `$$…$$`) |
| `.table-wrap` > `table` | Table. Use `.num` for right-aligned numbers. |
| `.code` > `.code-head` + `pre` | Code excerpt |
| `.note` | Callout for a design decision or limitation |
| `.stats` > `.stat` | Headline numbers |
| `.cards` > `.card` | Link tiles |
| `.todo` | Placeholder for data we still need |

Diagram SVGs use `class="dg"` together with `box`, `box-soft`, `box-strong`, `ln`, `ln-strong`, `dash` and `t-sm`.
