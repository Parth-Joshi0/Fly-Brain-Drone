# FruityFly Whitepaper Site

Static site built with plain HTML, CSS and JS. Vite is used only for the dev server and the build.

```
npm install
npm run dev      # local server with live reload
npm run build    # output to dist/
```

## Layout

```
index.html         the whole whitepaper, one page
_template.html     examples of every building block
css/style.css      all styles, grouped into numbered sections
js/main.js         header bar, Contents sidebar, section numbers, footer, math
assets/            images and icons
```

The header bar, Contents sidebar and footer are generated by `js/main.js`. Section numbers (1, 1.1, …) are added automatically, so don't type them into headings. Each `<section id>` with an `h2` is a top-level part, and each `h3` inside it is a numbered subsection.

## Add a section

1. Add a `<section id="name">` with an `<h2>` to `index.html`.
2. To put it in the header bar too, add `{ href: "#name", label: "Nav label" }` to `SECTIONS` in `js/main.js`.

## Building blocks

These are all shown in `_template.html`:

| Class | Use |
|---|---|
| `section id=…` + `h2` | A numbered section, listed in Contents. `h3` inside it becomes a subsection. `id="references"` stays unnumbered. |
| `figure` > `.fig-body` + `figcaption` | Diagram or image |
| `.eq` | Display math (KaTeX, `$$…$$`) |
| `.table-wrap` > `table` | Table. Use `.num` for right-aligned numbers. |
| `.code` > `.code-head` + `pre` | Code excerpt |
| `.note` | Callout for a design decision or limitation |
| `.todo` | Placeholder for data we still need |

Diagram SVGs use `class="dg"` together with `box`, `box-soft`, `box-strong`, `ln`, `ln-strong`, `dash` and `t-sm`.
